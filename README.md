# Linkliste für Edge und Chrome

**[Download (.nvda-addon)](https://github.com/sappelmueller/linkliste/releases/latest/download/linkliste.nvda-addon)**

## Deutsch

Die Linkliste zeigt die Links der aktuellen Webseite in Microsoft Edge und Google Chrome. Öffne sie mit **NVDA+F8**, suche per Suchfeld oder Buchstabensprung und öffne den ausgewählten Link mit **Enter**. Lade die Datei über den Link oben herunter, öffne sie zur Installation und starte NVDA anschließend neu.

[Mitgelieferte Hilfe](doc/de/readme.html)

## English

Links List for Edge and Chrome shows links on the current webpage in Microsoft Edge and Google Chrome. Press **NVDA+F8**, find a link using the search field or first-letter navigation, and press **Enter** to open it. Download the add-on above, open the file to install it, and restart NVDA.

[Included help](doc/en/readme.html)
