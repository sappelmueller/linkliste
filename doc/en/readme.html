Links List for Edge and Chrome

Version 2.0

Press NVDA+F8 to open a fast, searchable list of links in the current Microsoft Edge or Google Chrome page. Focus starts on the first displayed link. The interface currently uses German labels.

Commands

  • NVDA+F8: open the list in Edge or Chrome once the NVDA browse mode document is ready.
  • Up and Down: select the previous or next link.
  • Home and End: select the first or last displayed link.
  • Page Up and Page Down: move several entries.
  • Enter: open the selected link, including from the search field.
  • Tab and Shift+Tab: move between the search field, links and buttons.
  • Alt+1: focus the links.
  • Alt+2: focus the search field and select its contents.
  • Alt+3: refresh the list and clear the filter.
  • Escape: close the dialog.

Zum Link springen (Move to link) moves the NVDA browse mode cursor to the selected link without opening it. Closing the list returns control to the page.

Search and first-letter navigation

The search field filters links by a case-insensitive substring. The status below the list gives the number displayed. Clear the field or refresh to remove the filter.

Typing in the links list moves to the next matching prefix. Repeating a single character cycles through matches. Quickly typing different characters builds a prefix; a one-second pause starts a new input. Arrow keys and Backspace reset the prefix.

Characters, navigation keys and Enter pressed while opening are replayed in order. A saved search is restored on reopening; if it has no matches on the current page, the list starts without a filter.

Collection and reliable activation

The add-on enumerates links throughout the current NVDA document without a fixed limit. Identically named links remain separate entries. Image and unnamed links are retained when exposed as links in NVDA's document. Content that the website has not loaded or has not made accessible to the browser and NVDA cannot be collected.

Opening invokes only the exact selected accessible link object. There is no fallback by name, index, neighbouring element, screen coordinates or mouse click. If the object is no longer available unambiguously, or the document has been replaced, nothing else is activated. Refresh the list or reopen it on the desired page.

Refresh after the page loads additional content. A failed refresh preserves the existing list. An empty page can also open a list and be refreshed later.

Layout

The dialog is resizable. Buttons adapt to the available width, moving into multiple rows when necessary. Captions wrap at very large text sizes. On extremely small work areas, the entire dialog remains scrollable and Tab brings the focused control into view.

Native controls use system fonts and colours. Window size and position are remembered and constrained to the available monitor, including monitors with negative coordinates and changed scaling.

Change log

Version 2.0 – 19 October 2026

  • Added Google Chrome alongside Microsoft Edge. NVDA+F8 remains the shortcut.
  • Reworked spacing, text-dependent sizes, responsive button rows and scrolling on small work areas.
  • Corrected window restoration for multiple monitors and changed scaling.
  • Fixed duplicate opening, stale search timers, refresh error handling and saving on close.
  • Hardened selection and early input handling; added document and object identifier validation.
  • Move to link now resolves the current position from the exact link object.
  • Kept distinct links, including duplicate names, with no fixed collection limit.
  • Updated German and English help and corrected the obsolete shortcut.

Version 1.8.5
