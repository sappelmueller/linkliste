Audit report – Links List 2.0

19 October 2026. Based on reliableEdgeLinks 1.8.5.

Back to help

Scope and results

All supplied Python code, the manifest and both help files were reviewed. Google Chrome support was added to the existing implementation. 59 automated functional tests and 60 layout cases pass.

No real Windows installation or NVDA session with Edge or Chrome was available. Functional tests use controlled NVDA and browser test doubles. Real wxPython 4.2.1 GTK controls were exercised and rendered on Linux. These checks do not establish Windows screen-reader behaviour or live browser compatibility.

Corrections

  • Chrome support added while retaining the existing add-on identity, configuration and NVDA+F8 shortcut.
  • Duplicate dialogs prevented; popup and keyboard capture cleanup hardened.
  • Early input handoff synchronized; Alt, Control and Windows combinations are preserved.
  • Stale search timers stopped and selection, navigation and immediate Enter handled consistently.
  • Saved state handled for all closing paths; refresh errors preserve the previous list.
  • Document availability, URL, buffer identity and available link identifiers validated before actions. Mutable handles are stored by value.
  • Defunct or unavailable objects rejected without activating substitute links.
  • Move to link resolves a fresh position from the exact object.
  • Saved filters with no matches are cleared on opening. Duplicate and unnamed links retained without a fixed collection limit or resolving live link objects during construction.
  • Text-dependent control sizes, consistent spacing, responsive button rows, multiline captions, wrapped status text and scrolling for tiny work areas implemented.
  • Explicit Tab order keeps focused controls visible and skips disabled actions. Native system fonts and colours retained.
  • Window restoration handles negative monitor coordinates, removed monitors and changed DPI.
  • Access keys corrected; both help files updated and change logs included.

Validation

59 functional tests cover 10,000 links, duplicates, unnamed links, Unicode filtering, immediate Enter, arrow and Tab navigation, timer cleanup, collection/refresh/construction errors, stale documents and identifiers, exact activation and jumping, capture ownership, and modal lifecycle for Edge and Chrome application names.

60 layout cases combine four work areas (1280 × 800, 1024 × 600, 480 × 640 and 360 × 300), five text enlargement factors (100, 125, 150, 200 and 300 percent), and normal, empty and no-match lists. Checks cover button overlap, caption size and reachability of focused controls. Rendered layouts were inspected. Python syntax, HTML links and ZIP integrity were also checked.

Pending Windows validation

Install over 1.8.5; check NVDA announcements and native keyboard events; test real pages in Edge and Chrome, especially OGame, dynamic content, image links and frames; check high-contrast themes and transitions between monitors with different DPI settings.

Only links exposed in the current NVDA document can be collected. Unloaded or inaccessible website content cannot be forced into the list.

API behaviour was checked against the primary NVDA release-2026.1 source for browse mode, virtual buffers, Chromium backends and input capture, and the wxPython window documentation.
